# 💬 Простой Чат-бот

Интерактивный чат-бот на чистом HTML, CSS и JavaScript (Vanilla JS), разработанный в рамках учебного проекта.

## ✅ Выполненный функционал (согласно заданию):
- [x] **Отправка сообщений:** Работает как по клику на кнопку "Отправить", так и по нажатию клавиши `Enter`.
- [x] **Имитация задержки ответа:** Реализован индикатор "Бот печатает..." с таймером (`setTimeout`), чтобы общение выглядело естественно.
- [x] **Очистка истории:** Кнопка "Очистить историю" полностью сбрасывает чат и возвращает приветственное сообщение бота.
- [x] **Расширенная база ответов:** Бот реагирует не только на базовые команды, но и на дополнительные фразы (о создателе, программировании, времени и т.д.).
